# Behavioral Scoring: Predicting 90+ DPD

Модель поведенческого скоринга для прогнозирования просрочки 90+ дней у действующих клиентов банка.

## Задача
Бинарная классификация: для каждого наблюдения «клиент × месяц» предсказать, возникнет ли просрочка ≥ 90 дней в течение ближайших 12 месяцев.

## Данные
- 8 таблиц: транзакции по MCC, кредитный рейтинг, описание клиента/кредита, ипотека, макроэкономика, просрочки.
- Итоговая таблица: 438 379 наблюдений, 27 признаков (включая 8 новых).
- Разбиение по времени: train (2013–2017), calibration (2018), test (2019).
Данные не включены в репозиторий, пожалуйста, скачайте их с [исходного адреса/внутреннего банковского хранилища] и поместите в папку data/

## Модель
- **Алгоритм:** RandomForestClassifier с `class_weight='balanced'` (`n_estimators=129`, `max_depth=19`, `min_samples_leaf=19`, `max_features='sqrt'`).
- **Калибровка:** `CalibratedClassifierCV` (sigmoid).
- **Порог:** 0.11.

## Результаты на тесте (2019)
| Метрика | Значение |
| :--- | :--- |
| ROC-AUC | 0.9659 |
| Approval Rate | 88.78% |
| Default Rate | 0.71% |
| Missed Defaults Rate | 12.98% |

## Ключевые признаки
1. `tenure_months` (16.1%) — стаж клиента
2. `доход` (8.7%)
3. `MCC_5411` (7.8%) — траты на продукты
4. `total_spend` (7.2%)
5. `возраст` (6.3%)
